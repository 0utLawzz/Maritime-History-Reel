---
name: Product Direction
description: Agreed direction for evolving the history-reel studio into a shared production platform.
---

The product should evolve from a single-user reel dashboard into a shared production studio. Use Replit login, with an administrator controlling permissions for editors, publishers, and viewers. Begin bulk workflows with CSV import. Content entry should remain manual or bulk-imported; automatic AI script writing is intentionally not part of the initial scope.

**Why:** The user wants a controlled team workflow for producing many history reels while keeping editorial decisions manual.

**How to apply:** Prioritize authentication and roles, CSV import, metadata automation, media selection, MP4 rendering, publishing integrations, and bulk processing in incremental milestones. Treat mobile as a later companion product.
