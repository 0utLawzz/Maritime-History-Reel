> Full-stack platform for creating, managing, and publishing 9:16 short-form history reels to Facebook Pages, Instagram Reels, and YouTube Shorts — built on a pnpm monorepo with React, Express, and PostgreSQL.

## Topics / Keywords
`maritime-history` `reels` `youtube-shorts` `instagram` `facebook` `react` `express` `postgresql` `pnpm-monorepo` `video-studio` `custom-automation`

## Quick Start
```bash
pnpm install
# Set DATABASE_URL
pnpm --filter @workspace/db run push
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/studio-dashboard run dev
```
